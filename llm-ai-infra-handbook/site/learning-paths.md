# 学习路径

不必按目录从头读到尾。先选择目标，再沿因果链逐层深入。

## LLM 算法与训练

数学与性能模型 → 语言建模 → Transformer → 注意力 → 数据工程 → 预训练 → 微调 → 对齐 → 评估。

适合希望理解模型为何有效、如何训练以及如何判断训练结果的人。

## 训练基础设施

数学与性能模型 → Transformer → 预训练 → 加速器与服务器 → GPU 内核 → 分布式训练 → 训练平台 → 集群运营。

适合负责训练框架、集群、网络、存储和稳定性的工程师。

## 推理基础设施

数学与性能模型 → 注意力与 KV 状态 → 加速器与服务器 → GPU 内核 → 推理算法 → 推理运行时 → 可观测性与成本。

适合负责推理引擎、在线服务、容量和性能优化的工程师。

## RAG 与 Agent 系统

语言建模 → 模型评估 → 推理服务 → RAG 与检索 → Agent 与上下文 → 安全治理。

适合构建知识问答、工具调用和生产级智能体应用的人。

## 每张卡片怎么学

1. 先尝试回答卡片标题表达的问题。
2. 用“一句话结论”校准自己的心智模型。
3. 沿数据流写出计算、内存、通信或 I/O 路径。
4. 用“具体例子”和“观测与排障”验证结论。
5. 最后回答“面试追问”，确认自己能迁移而不只是复述。
