## 一句话结论

- **事实性幻觉**：输出与客观事实冲突（如"李白是唐朝诗人"对，但编出不存在的论文）。
- **忠实性幻觉**：输出与**提供的资料**冲突（RAG 里尤其坑——模型不服从检索内容）。
- **检测**：SelfCheckGPT（多次采样一致性）、NLI 矛盾检测、检索验证、不确定性估计。
- **缓解全谱系**：数据增强/知识对齐、RAG+引用、解码约束（如 grounding）、后验校验、RLHF 教"不知道"。

## 原理推导

### 为什么会幻觉

1. **知识边界**：参数化知识有截止与错误，模型倾向"编一个流畅答案"而非承认不知。
2. **暴露偏差（exposure bias）**：自回归训练时每一步输入是真实前文，推理时却是自己生成的（可能已错）→ 错误累积。
3. **解码随机性**：temperature 高时更易走偏；即使 greedy 也可能因训练数据本身含错而"自信地错"。
4. **知识冲突**：参数记忆 vs 检索资料不一致，模型可能选错的那个（忠实性失败）。

### 检测手段

- **SelfCheckGPT**：同一 prompt 采样多次，若彼此不一致 → 大概率幻觉（事实性内容应稳定）。
- **NLI / 矛盾检测**：把"声明"和"检索段落"送 NLI 模型，判 entail/contradict。
- **检索验证**：要求模型输出带引用，再校验引用是否真支持该句。
- **不确定性估计**：用生成概率的熵/方差，低置信处更可能错。

### 缓解（从训练到推理）

| 层面 | 手段 |
|---|---|
| 数据 | 知识增强、事实性 SFT 数据、去毒 |
| 架构/检索 | RAG（让模型基于资料答）+ 强制引用 |
| 解码 | 约束解码（只生成检索片段中的实体）、grounded generation |
| 后验 | 答案与资料一致性校验、Self-Consistency 投票 |
| 对齐 | RLHF/DPO 奖励"诚实"、训练"我不知道"样本 |

**关键点**：RAG **不消除**幻觉，只是把"参数记忆"换成"检索资料"——若资料错/未召回/模型不服从，仍会 hallucinate（忠实性幻觉）。所以要"检索 + 引用 + 校验"三件套。

## 具体例子

- **医疗问答**：RAG 检索指南 + 强制每条结论带指南条款引用 + 后验 NLI 校验引用是否真支持。仍要求模型对检索无覆盖的问题答"指南未提及"。
- **代码 Agent**：生成代码后用执行/单测验证（observation 即事实），比纯生成可靠。
- **"我不知道"训练**：在 SFT/对齐数据里加入"无法回答时明确拒答"样本，降低编造率。
