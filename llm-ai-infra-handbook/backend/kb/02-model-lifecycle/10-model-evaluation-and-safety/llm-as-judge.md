## 一句话结论

- **打分形式**：单点打分（1~10）、pairwise 比较（A 还是 B 好）、参考引导（给标准答案比对）。
- **系统性偏差**：① 位置偏差（偏好放前面的）② 长度偏差（偏好更长）③ 自我偏好（偏好自己生成的风格）④ 分数压缩（打分集中在中间）。
- **消除**：双向评估（A/B 与 B/A 各评一次取一致）、随机顺序、few-shot 校准、多评委投票。
- **一致性度量**：与人类标注算 Cohen's κ / Spearman / 胜率一致性。

## 原理推导

### 为什么用 LLM 当评委

人工标注贵且慢，规则抽取（正则/关键词）覆盖有限。强模型（GPT-4 级）对"有用性/流畅性"的判分与人类高度相关（[LLM-as-a-Judge, 2023]），成本降 100×。

### 打分形式对比

- **单点打分**：给 A、B 各打 1~10。简单但绝对尺度不稳、有分数压缩（都打 7~8）。
- **pairwise**：直接问"哪个更好" → 更稳定、与人类偏好对齐更好，是主流。
- **参考引导（reference-guided）**：给标准答案，让评委判"与标准的吻合度"，适合有标准答案的任务。

### 四种系统性偏差

1. **位置偏差**：pairwise 中无论质量，放前面的常被判"更好"。→ 双向评估抵消。
2. **长度偏差**：越长越被当"更完整"而给高分。→ 截断/长度归一，或要求只评质量。
3. **自我偏好（self-enhancement）**：模型偏好与自身生成风格相近的答案（即使质量未必高）。→ 用"不同家族"的评委、或多评委。
4. **分数压缩（central tendency）**：避免给极端分，分布挤在中间 → 用 pairwise 代替绝对打分。

### 消除手段小结

| 方法 | 作用 |
|---|---|
| 双向 / 随机顺序 | 抵消位置偏差 |
| few-shot 校准 | 给评分卡(rubric)与示例，拉齐尺度 |
| 多评委投票 | 降单一模型自我偏好/随机性 |
| 链式思考(CoT) | 先写理由再打分，提升可靠性 |
| 与人类一致性校验 | Spearman/κ 监控，偏离则换评委 |

## 具体例子

- **Arena 风格 pairwise**：随机把 A、B 顺序打乱，各评一次，取多数一致为最终结果 → 位置偏差基本消除。
- **代码评测**：不用评委判"代码对不对"（模型不擅长），改用**执行测试**客观判分，评委只评"可读性/风格"。
- **一致性**：某评委与人工标注的 Spearman = 0.7 可接受，<0.5 需换更强评委或加校准。

## 代码速记

```python
# 双向 pairwise 评委（抵消位置偏差）
def judge_pairwise(judge, a, b, question):
    p1 = judge(question, a, b)   # 问 a 是否优于 b
    p2 = judge(question, b, a)   # 顺序反转
    # 只有两次结论一致才采信
    if p1 == p2: return p1
    return "tie_or_unreliable"
```
