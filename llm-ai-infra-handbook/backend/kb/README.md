# 知识库导航

知识库按“第一性原理 → 模型生命周期 → AI 基础设施 → LLM 系统”的因果链组织，而不是按工具或厂商划分。当前共 20 个模块、163 张知识卡片。

## 四条主线

1. `01-llm-foundations`：建立数学、语言建模、Transformer、注意力和现代架构基础。
2. `02-model-lifecycle`：贯通数据、预训练、微调、对齐与模型评估。
3. `03-ai-infrastructure`：从加速器和内核走到分布式训练、训练平台、推理服务和集群运营。
4. `04-llm-systems`：构建 RAG、Agent，以及安全、治理与供应链能力。

## 推荐学习路径

- **LLM 算法**：01 → 02 → 03 → 04 → 05 → 07 → 08 → 09 → 10。
- **训练 Infra**：01 → 03 → 07 → 11 → 12 → 13 → 14 → 17。
- **推理 Infra**：01 → 03 → 04 → 11 → 12 → 15 → 16 → 17。
- **RAG / Agent**：02 → 10 → 16 → 18 → 19 → 20。

## 内容边界

- 模型评估关注“模型能力是否可靠”，系统基准关注“服务在目标负载下是否达标”。
- 推理算法关注减少计算、内存和带宽，推理运行时关注并发、调度、路由和服务目标。
- 分布式训练关注一次 step 的多卡执行，训练平台关注长期作业的供给、恢复和血缘。
- RAG 负责证据检索与引用，Agent 负责状态、工具和多步行动。
- 安全评测衡量风险，安全工程负责权限、隔离、审计和响应。

## 卡片规范

每张卡片使用 YAML frontmatter，至少包含 `id`、`title`、`module`、`tags`、`difficulty`、`freq`、`updated`、`summary`、`source` 和 `questions`。正文需要给出结论、机制、工程权衡、例子、观测排障与追问。

运行 `python tools/validate_frontmatter.py` 可检查数量、唯一 ID、模块归属、来源和问法完整性。
